# 功能概述

- 一个网页，可以导入用户的微信/支付宝/银行流水，解析到数据库。可以通过编写sql对消费记录做统计并通过曲线图展示，如月度每日支出汇总、每日收入汇总，以及对消费记录做分类，对分类统计做图标展示。  
- 导入文件格式有pdf、xlsx、csv,要求能够自动识别。
- sql可以让用户编写，实时展示，类似grafana的dashboard。对于常用的sql，可以提供模板，在导入文档后自动展示。  
- 由于涉及用户隐私，因此程序不能有任何和服务器的数据交互，直接在浏览器端运行。  

# 交互细节

- 打开网页，直接呈现一个导入文件的界面，用户可以选择导入文件，也可以直接拖动文件到网页上。
- 导入文件后，跳转到sql编写页面。页面直接展示出几个常用模板。用户可以自己编写sql新增图表,点击保存的图标，会放在dashboard页卡中。
- 导入的文件、解析出的数据、数据库文件、编写的sql，都保存在浏览器本地。  
- 当后面再打开网页时，直接进入dashboard页面，展示已经编写的图表。
- 所以一共有三个页卡，一个是进入网站的导入文件页卡，一个是编写并预览sql的页卡，一个是纯展示图标的页卡。
- 用户再次进入网站，直接加载之前解析好、编写好的图表。  

# 技术实现
sqliteviz可以导入csv文件，用户可以编辑sql展示图表。但图表不能在页面展示，只能下载。
对sqliteviz进行改造，可以识别更多种类文件，可以直接在页面展示图表。
